# 运动详情页多运动升级手工测试清单

日期：2026-07-28  
适用范围：运动详情页「概览」/「复盘」多运动升级  
任务源：`docs/运动详情页多运动升级开发任务清单.md`

## 1. 测试环境

| 项 | 要求 |
| --- | --- |
| 启动方式 | `python main.py` 或项目当前桌面开发启动方式 |
| 视口 | 桌面宽屏、约 900px 中宽、约 390px 窄屏 |
| 控制台 | 保持 DevTools 可见，观察报错和重复请求 |
| 数据 | 优先使用真实活动；缺少真实样本时可用匿名 mock fixture 复核字段语义 |

## 2. 覆盖矩阵

| 模式 | 样本 sport_type | 概览预期 | 复盘预期 |
| --- | --- | --- | --- |
| `endurance_outdoor` | `running` / `trail_running` | 保留地图、Hero、圈速 | 保留跑步复盘、GAP、疲劳带和事件 |
| `endurance_outdoor` | `cycling` / `road_cycling` / `mountain_biking` | 保留地图、功率/踏频事实 | 骑行卡片和功率/踏频 lane，不套跑步配速 |
| `endurance_indoor` | `treadmill_running` | 不显示轨迹失败，显示室内摘要 | 不显示路线、GAP、地形负荷或天气压力 |
| `endurance_indoor` | `indoor_cycling` | 无 GPS 也可显示功率、踏频、心率 | 只显示功率、心率、踏频等事实 lane |
| `swim_pool` | `lap_swimming` | 显示 /100m、SWOLF、泳段语义 | 不显示 GAP、爬升、跑步或骑行结论 |
| `swim_open_water` | `open_water` | 可显示开放水域主视觉和游泳指标 | 只解释已有游泳事实，水温缺失时降级 |
| `strength` | `strength_training` | 无结构化动作时显示受限概览 | 不画耐力图，不猜动作、肌群、组数、重量 |
| `mobility_recovery` | `yoga` / `breathing` | 显示恢复类摘要 | 不做竞速化表现评价或能量断档结论 |
| `generic_session` | `cardio` / `training` / `hiit` | 只展示已有基础事实 | 受限说明，不生成完整耐力复盘 |
| `not_supported` | `unknown` / `driving` | 不默认跑步或骑行 | `not_applicable`，不画图、不出八卡 |

## 3. 基础流程

| 用例 ID | 操作 | 预期结果 | 通过 |
| --- | --- | --- | --- |
| MDT-07-001 | 从活动列表打开任一活动详情 | 默认停留在「概览」Tab | ☐ |
| MDT-07-002 | 切到「复盘」Tab | 首次切换才加载复盘，加载后不重复请求 | ☐ |
| MDT-07-003 | 复盘 → 概览 → 复盘 | 已加载活动不出现旧图表残留或重复动画异常 | ☐ |
| MDT-07-004 | 打开 A 活动并切到复盘，再关闭打开 B 活动 | B 活动默认回到概览，A 的图表、卡片、受限文案不残留 | ☐ |
| MDT-07-005 | 后端返回 code 非 0 或 data 为空 | 复盘显示空态，不渲染过期图表或卡片 | ☐ |

## 4. 响应式和长文案

| 用例 ID | 操作 | 预期结果 | 通过 |
| --- | --- | --- | --- |
| MDT-07-101 | 桌面宽屏查看概览和复盘 | 主视觉、指标卡、图表和侧栏无重叠 | ☐ |
| MDT-07-102 | 中宽窗口查看概览和复盘 | 侧栏和卡片自然换行，标题不压住内容 | ☐ |
| MDT-07-103 | 窄屏查看概览和复盘 | 按钮、Tab、图层控制、卡片和空态文案不溢出 | ☐ |
| MDT-07-104 | 使用长 advice / disclaimer / not_applicable 文案 | 文案自然换行，不撑破卡片或遮挡后续内容 | ☐ |
| MDT-07-105 | 少卡片或无卡片 profile | 布局保持稳定，不留下空白八卡骨架 | ☐ |
| MDT-07-106 | 无轨迹、无分段、无曲线活动 | 显示对应空态，不出现轨迹失败误导或空 ECharts | ☐ |

## 5. AI Prompt 边界

| 用例 ID | 操作 | 预期结果 | 通过 |
| --- | --- | --- | --- |
| MDT-07-201 | 对 `strength_training` 生成 AI prompt | 明确结构化动作数据不足，不猜动作、组数、重量、肌群 | ☐ |
| MDT-07-202 | 对 `yoga` / `breathing` 生成 AI prompt | 不出现竞速化表现、后程耐久、能量断档结论 | ☐ |
| MDT-07-203 | 对 `indoor_cycling` 生成 AI prompt | 不出现路线、爬升、天气压力、地形推断 | ☐ |
| MDT-07-204 | 对 `lap_swimming` 生成 AI prompt | 不出现 GAP、跑步配速或骑行功率推断 | ☐ |
| MDT-07-205 | 对 `unknown` 生成 AI prompt | 不默认跑步/骑行/游泳/徒步，说明不适用原因 | ☐ |

## 6. 本轮非目标

- 不验收结构化力量动作、肌群热图、重量、训练容量或渐进负荷趋势。
- 不验收新的 FIT 消息解析。
- 不验收打包、DMG/MSI 或发布脚本。
