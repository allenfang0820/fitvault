# 轨迹分析工具 Cesium 升级与 DEM 地形 POC 开发交付手册

> 日期：2026-07-30
> 范围：轨迹分析工具功能页的 Cesium 升级、真实 DEM 地形图层、海拔墙退役、既有轨迹分析交互保留。
> 状态：后续开发的重要参考依据。实施前必须先拆分任务清单，再按任务清单执行。

## 1. 改造目标

本次短期改造目标是完成轨迹分析工具地图底座升级 POC，而不是重做轨迹分析页，也不是引入中期的 MapLibre + deck.gl 2D 诊断页。

目标包括：

- 将轨迹分析工具使用的 Cesium 从当前 `1.105.1` 升级到 `1.143` 方向，并完成兼容性验证。
- 新增用户主动选择的真实 DEM 地形图层。
- DEM 不进入安装包，不默认下载，使用会话临时缓存。
- 程序退出后删除本次会话 DEM 缓存，启动时清理上次异常退出残留。
- 彻底退役海拔墙，减少视觉和代码冗余。
- 保留当前 CP 点、里程点、最高点、进度滑块、底部剖面图联动等既有轨迹分析能力。

一句话边界：

**在保留现有轨迹分析交互资产的前提下，升级 Cesium，引入用户主动切换的临时 DEM 真实地形，并彻底移除海拔墙。**

## 2. 产品原则

### 2.1 2D / 3D 与 DEM 分工

现有 2D / 3D 滑块继续只负责相机视角，不负责地形数据加载。

- `2D`：平面查看轨迹和底部海拔剖面。
- `3D`：在三维视角中查看轨迹。
- `真实地形`：独立图层开关，由用户主动选择。

产品心智为：

**滑块管怎么看，图层管看什么。**

### 2.2 DEM 与活动海拔事实分层

DEM 只作为地图环境图层，不改变活动记录事实。

- FIT / 手表海拔：活动记录事实，继续用于底部海拔剖面图、爬升统计、复盘和相关指标。
- DEM 高程：真实地形显示层，只用于地图环境展示。
- 高程差异诊断：未来可选能力，本次不做。

本次禁止：

- 禁止用 DEM 覆盖 FIT 海拔。
- 禁止改写活动记录、轨迹点或数据库中的原始海拔。
- 禁止修改累计爬升、最高海拔、复盘等后端事实算法。
- 禁止在复盘中默认切换为 DEM 高程。

### 2.3 海拔墙退役

海拔墙不再保留。

- 不作为默认图层。
- 不保留用户入口。
- 不保留内部调试开关。
- 不保留隐藏兼容能力。
- 清理相关 entity、状态、样式、开关、测试断言和死代码。

退役原因：

- 底部已有半透明海拔剖面图，能以横轴展开方式表达手表记录海拔。
- 海拔墙原本用于近似表达山地地形；真实 DEM 引入后，这一职责由 DEM 地形承担。
- 海拔墙与 DEM 地形大概率不吻合，继续保留会混淆“设备记录海拔”和“真实地形高程”。

## 3. 交互方案

### 3.1 保留 2D / 3D 滑块

现有 2D / 3D 滑块继续存在，并保持当前交互语义：

- 控制 camera pitch / 视角切换。
- 不触发 DEM 下载。
- 不改变地形 provider。
- 不改变轨迹数据来源。

实施时必须重点保护现有 `lookAt` / `lookAtTransform` 释放链路，避免滑块拖拽后相机锁死。

### 3.2 新增地形图层控制

新增独立图层控制，建议入口文案：

```text
图层
- 标准地形
- 真实地形
```

交互规则：

- 默认使用标准地形。
- 用户点击 `真实地形` 后，直接加载当前轨迹附近 DEM。
- 不弹出确认弹窗。
- 图层按钮显示轻量状态，例如 `真实地形 · 加载中`。
- 加载成功后保持 `真实地形` 选中。
- 加载失败时静默回退到标准地形，并可给轻量 toast 或短暂状态提示。
- 下次打开程序不复用上次 DEM；用户如果再次选择真实地形，再重新加载。

### 3.3 DEM 会话临时缓存

短期 POC 使用会话临时缓存，不做长期缓存。

规则：

- DEM 不进入安装包。
- 默认不下载 DEM。
- 只有用户主动选择 `真实地形` 时才加载 DEM。
- 下载范围按当前轨迹 bbox 外扩少量缓冲区。
- DEM 存入脉图自管 session cache 目录，不写入运动记录数据库。
- 程序退出时删除当前 session DEM。
- 程序启动时清理上次异常退出留下的旧 session DEM。

建议目录形态：

```text
~/Library/Application Support/FitVault/cache/dem-session/{session_id}/
```

本次暂不做：

- 不做长期 DEM 缓存。
- 不做离线地形包管理。
- 不做缓存上限 UI。
- 不做“保存离线地形”高级选项。

## 4. 必须保留的既有能力

Cesium 升级、DEM 接入和海拔墙删除不得导致以下功能丢失或退化：

- CP 点展示。
- CP 点新增。
- CP 点编辑。
- 里程点展示。
- 里程点开关。
- 最高点 / 坡顶等标记展示。
- 最高点 / 坡顶等标记开关。
- 进度滑块。
- 轨迹进度切片显示。
- 底部半透明海拔剖面图。
- 底部剖面图点击 / 定位联动。
- 活动详情页轨迹缩略图跳转轨迹分析工具。
- 2D / 3D 视角滑块。
- 指南针 / 归北。
- 自动旋转，若当前产品仍保留该入口。
- 导入 GPX / FIT 后加载轨迹并定位。

任何实现方案若需要重写轨迹 entity 或 camera 控制，必须先证明上述能力有等价替代与回归测试。

## 5. 技术范围

### 5.1 允许修改

本次 POC 允许触碰：

- `lib/Cesium` 本地 Cesium 构建资源。
- `track.html` 中 Cesium 初始化、viewer 配置、terrain provider 切换。
- `track.html` 中轨迹渲染的地形贴合 / 近地显示参数。
- `track.html` 中图层控制 UI 和状态。
- `track.html` 中海拔墙相关代码删除。
- DEM 会话缓存管理相关前后端桥接代码。
- 与以上功能直接相关的聚焦测试。

### 5.2 禁止修改

本次 POC 禁止触碰或改变：

- FIT / GPX 解析语义。
- 活动记录数据库事实字段。
- 活动详情页概览 / 复盘合同。
- 疲劳复盘算法和 prompt。
- 累计爬升、最高海拔、距离、配速等统计口径。
- 运动记录导入链路。
- 中期 MapLibre + deck.gl 路线诊断页。

## 6. 实施建议

建议按三条线拆分任务：

### 6.1 Cesium 兼容线

目标：

- 升级本地 Cesium 构建资源。
- 确认 `window.CESIUM_BASE_URL`、Workers、Widgets、Assets 路径正常。
- 确认当前 viewer 初始化参数在新版本下可运行。
- 确认无 DEM 时仍可正常使用标准地形。

重点风险：

- Workers 路径变化。
- Cesium API 兼容性变化。
- 相机控制行为变化。
- 现有 CDN fallback 与本地资源版本不一致。

### 6.2 真实地形线

目标：

- 新增地形图层开关。
- 支持标准地形与真实 DEM provider 切换。
- 加载当前路线附近 DEM。
- DEM 使用会话临时缓存。
- 加载失败时回退标准地形。

重点风险：

- 国内网络访问 DEM 服务不稳定。
- DEM tile 范围估算过大导致下载慢。
- terrain provider 切换后轨迹、CP 点和标记高度异常。
- 退出清理未执行，导致临时文件残留。

### 6.3 海拔墙退役线

目标：

- 删除海拔墙 entity 创建和更新。
- 删除海拔墙相关状态、样式、开关、注释和测试断言。
- 确认底部海拔剖面图仍正常显示和联动。
- 确认无 DEM 时不再用海拔墙模拟地形。

重点风险：

- 删除时误伤轨迹高度数组、进度切片或剖面图数据。
- 删除 wall entity 时误删 completed / remaining track entity。
- 测试中仍存在旧海拔墙断言。

## 7. 验收标准

### 7.1 基础场景

至少使用以下真实轨迹验收：

- 城市跑步。
- 山地 / 越野跑。
- 骑行爬坡。

每条轨迹均需验证：

- 标准地形下轨迹正常加载。
- 真实地形开关可用。
- 真实地形失败时可回退。
- 2D / 3D 滑块正常。
- 底部海拔剖面图正常。
- 退出重启后 DEM 临时缓存被清理。

### 7.2 既有功能回归清单

每条户外轨迹必须逐项点检：

- CP 点可见。
- CP 点可新增。
- CP 点可编辑。
- 里程点可见。
- 里程点开关有效。
- 最高点 / 坡顶标记可见。
- 最高点 / 坡顶标记开关有效。
- 进度滑块拖动后轨迹进度正常。
- 剖面图点击 / 定位联动正常。
- 指南针 / 归北正常。
- 自动旋转正常，若该入口仍保留。
- 活动详情页跳转轨迹分析工具正常。

### 7.3 海拔墙退役验收

必须确认：

- 默认视图无海拔墙。
- 图层菜单无海拔墙入口。
- 内部状态无海拔墙开关。
- 代码中无活跃 wall entity 创建逻辑。
- 底部剖面图仍是唯一海拔剖面表达。

### 7.4 安装包与存储

必须确认：

- DEM 不进入安装包。
- Cesium 升级导致的安装包增长可接受。
- 首次启动不下载 DEM。
- 只有用户选择真实地形才下载 DEM。
- DEM 临时缓存不写入数据库。
- 退出和启动清理均可执行。

## 8. 非目标

本次不做：

- MapLibre + deck.gl 2D 路线诊断页。
- OpenMapTiles / PMTiles 离线矢量底图。
- 长期 DEM 缓存。
- 离线 DEM 包下载中心。
- DEM 高程校正活动记录。
- 设备海拔与 DEM 高程差异诊断层。
- 重做活动详情页概览 / 复盘。
- 重做 FIT / GPX 导入。

## 9. 给后续开发 Agent 的启动提示

请先阅读本手册，再阅读当前 `track.html` 中 Cesium 初始化、轨迹 entity 渲染、CP 点、里程点、坡顶 / 最高点、进度滑块和剖面图相关代码。

实施前必须先产出任务清单，任务清单至少包含：

- Cesium 资源升级任务。
- Viewer 初始化兼容任务。
- 地形图层开关任务。
- DEM 会话缓存任务。
- 海拔墙删除任务。
- CP / 里程 / 最高点回归任务。
- 2D / 3D 相机回归任务。
- 手测与自动化验收任务。

不要在没有任务清单的情况下直接修改业务代码。
