# FIT关键证据卡语义正确性优化事实边界冻结

> 日期：2026-08-06
> 关联任务：`docs/FIT关键证据卡语义正确性优化任务清单.md` / OT-00
> 结论：这是通用代码语义与健壮性问题，不是百锐腾专属兼容问题。

## 冻结结论

百锐腾 FIT 更稀碎，会把现有边界问题放大出来，但根因不应归结为“百锐腾 数据天生有问题，所以代码不用修”。

真正要修的是：

- 缺失速度被当成真实 0 速度
- stopped 过滤没有先确认速度事实可信
- near-zero distance 把坡度放大成异常值
- 前端把后端 `available / partial / unavailable / missing` 粗暴折成“数据不足 / 待接入”

## 明确不做

- 不做百锐腾特例
- 不做迈金 / 佳明 / 其他品牌特供分支
- 不把稀碎 FIT 插值成连续曲线
- 不用“看起来完整”掩盖事实缺口

## 允许继续优化的方向

- 通用语义清理
- 保守降级边界收紧
- 后端原因与前端文案对齐
- 代表性 FIT 回归矩阵

## 结论摘要

这次问题本质上是代码对 FIT 语义不够稳健，而不是某个品牌 FIT 需要特供修补。
