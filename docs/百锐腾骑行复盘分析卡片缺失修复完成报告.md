## 1. 结论

本次缺失卡片的主根因已修复：百锐腾 FIT 没有原生 `speed / enhanced_speed` 字段，旧逻辑把缺失速度零填充为 `0.0`，下游骑行卡片再把 `speed <= 1.0` 当作真实停顿，导致功率、心率、踏频样本被全量过滤。

修复后：

- 缺失速度不再伪装成观测 0 速度。
- 有距离/时间轴时，后端可生成带来源和质量标记的 `derived_distance_time` 速度。
- 骑行分析卡片只在速度事实可信时使用 `stopped` 过滤。
- 前端只展示后端 `status / reasons / evidence / summary.speed_*`，不从曲线补算结论。
- 重复距离/近零距离差不再放大出百万级坡度。

## 4. 仍需诚实降级的真实数据限制

本次修复目标不是“强行让所有卡片都有结论”，而是“有事实才输出，事实不足时说明真实原因”。该样本仍有以下天然限制：

- FIT 没有原生速度，速度来自后端 `distance/time` 推导，因此不能声称是设备直接观测速度。
- 心率正值点只有 1312 / 6564，覆盖稀疏；`metrics.hr_drift` 仍因速度/节奏波动过大返回不可用。
- 功率与踏频存在大量 0 值或滑行片段；卡片结论均基于过滤后的有效踩踏片段。
- `fatigue_zones` 为 `partial` 置信度，适合作为回看线索，不应解释成精确生理诊断。
