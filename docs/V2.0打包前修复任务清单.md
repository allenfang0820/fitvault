# 脉图 V2.0 macOS 打包前修复任务清单

## 0. 目标与发布口径

目标：将当前工作区收敛为可重现的 V2.0 macOS 发布源，完成 arm64 和
x86_64 安装包的新装、覆盖升级和核心功能验收。普通用户不需额外安装 Python、
Node.js、Garmin/COROS Skill 或其他开发环境。

本次明确接受网盘分发方式，不处理 Developer ID 签名、Apple 公证或
Gatekeeper 免提示分发。本清单的“可发布”结论不包含这三项能力。

## 1. 执行规则

- 任务必须按顺序执行；上一任务未通过，不得进入产物打包。
- 每项任务开始前执行 `git status --short`，保留并识别当前 dirty worktree。
- 不得 stash、reset、clean、覆盖或格式化无关改动。
- 每项完成后立即运行聚焦测试和 `git diff --check`。
- 涉及用户数据的升级验证只允许使用一致性备份或临时副本，不写真实库。
- 所有产物都必须从已收敛的发布源构建，不允许依赖未记录的本机文件。
- 真实账号授权、网络服务和 AI 凭据仍由用户在程序内配置；不把私密凭据打入安装包。

## 2. 非目标

- 不处理 Developer ID、Apple 公证、Gatekeeper 免提示或 Mac App Store。
- 不处理 Windows Python/Node/WiX 环境、PyInstaller onedir、MSI 或 Windows 安装验收；这些在另一台 Windows 打包机上建立独立任务清单。
- 不新增产品功能，不重做 UI，不修改运动指标公式。
- 不改写、重置或删除用户真实数据。
- 不将 Python、Node.js、npm、Skill 或开发依赖转嫁给普通用户手工安装。
- 不把 COROS token、Garmin tokenstore、LLM token、Cookie 或本机绝对路径写入产物。
