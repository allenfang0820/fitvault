## 1. 不变主链路

```text
Activity
  -> trail running aggregate facts / elevation range facts
  -> career_record_metric_results
  -> current_best / record_progression
  -> career_record_events
  -> Records Center / Timeline
```

- `Activity` 是唯一原始事实源。
- 前端只渲染后端 ViewModel，不计算越野跑指标、最大连续爬升、当前最佳、质量或里程碑。
- `career_record_metric_results` 是记录中心事实层。
- `career_record_events` 是可由 metric results 重建的派生层。
- 所有联动身份使用 `(activity_id, record_key, scope_hash)`；不得按某次活动或单个指标写特例。

## 2. 越野跑指标契约

| 指标 | metric series | current best | scope | 可用条件 |
| --- | --- | --- | --- | --- |
| `trail_longest_distance` | 必须接入 | 必须派生 | `sport_scope=trail_running` | Activity 有统一米制距离 |
| `trail_max_ascent` | 必须接入 | 必须派生 | `sport_scope=trail_running` | Activity 有累计爬升事实 |
| `trail_longest_elapsed_time` | 必须接入 | 必须派生 | `sport_scope=trail_running` | Activity 有有效历时 |
| `trail_max_altitude` | 必须接入 | 必须派生 | `sport_scope=trail_running` | Activity 有最高海拔事实 |
| `trail_max_single_climb` | 必须接入 | 必须派生 | `sport_scope=trail_running` | 轨迹/海拔流可计算连续爬升区间 |

状态约定：

- `available`：事实完整，允许进入 chart、current best、record progression 和 timeline。
- `validation_required`：事实可展示但质量存在风险；不得静默消失，默认不进入 current best，直到明确的后端 eligibility 规则允许。
- `sample_missing`：缺少距离、历时、爬升、最高海拔、轨迹或海拔区间样本；返回稳定 reason code。
- `unsupported`：仅用于未定义指标；不得用于本契约列出的越野跑 record key。

## 3. 源事实和单位契约

允许作为越野跑指标事实的来源：

- Activity summary 的距离、历时、累计爬升、最高海拔 canonical 字段。
- Activity 受控轨迹/points 中的距离、时间和海拔字段，用于最大连续爬升区间。
- 已保存的、可追溯到上述事实的 materialized metric result。

禁止：

- 将普通跑步、徒步或登山误归为越野跑。
- 从总爬升 `gain_m` / `ascent_m` 反推出最大连续爬升。
- 在前端补算任何越野跑记录事实。
- 返回 raw points、track_json、file_path、本地路径、设备序列号或 SQLite schema。

## 4. 生命周期和时间轴契约

对任意越野跑 Activity 的新增、更新、重新导入、软删除：

1. 失效或重算受影响的 `career_record_metric_results`。
2. 重建同一 record key / scope 的 `current_best` 和 `record_breaking`。
3. 清理失效 `career_record_events`，并晋升下一条有效成绩。
4. 时间轴按 `(activity_id, record_key, scope_hash)` 合并同态节点：
   - 当前最佳使用 `current_best` 语义。
   - 历史突破使用 `record_breaking` 语义。
   - 同一当前最佳不得仍被表达为“刷新纪录”。

不得新增越野跑专用事件表、前端补算分支或 candidate-only 终点。

## 6. 受控空态

- 无越野跑 Activity：`sample_missing`，reason code `trail_activity_missing` 或现有通用空态。
- 距离缺失：`sample_missing`，reason code `distance_missing` 或 `metric_missing`。
- 历时缺失：`sample_missing`，reason code `elapsed_time_missing` 或 `metric_missing`。
- 累计爬升缺失：`sample_missing`，reason code `ascent_missing` 或 `metric_missing`。
- 最高海拔缺失：`sample_missing`，reason code `max_altitude_missing` 或 `metric_missing`。
- 最大连续爬升缺轨迹/海拔区间：`sample_missing`，reason code `single_climb_range_missing`。
- 海拔流质量不足：`validation_required`，保留 reason codes；不得伪装成正式高置信。
